# Contributing to Meta-XoT-OSS-Rail

Thank you for wanting to help. The plugin is young, and what helps it most is hearing how it works for you:
what went well, where it got stuck, and where you still had to step in.

## Report a problem

Open an [issue](https://github.com/morreus/Meta-XoT-OSS-Rail/issues/new/choose) and choose **Bug report**. The
form asks what you typed, what happened, what you expected, and your Claude Code version, so the problem can be
found again. Leave out passwords, keys and private code.

## Suggest an idea

Open an [issue](https://github.com/morreus/Meta-XoT-OSS-Rail/issues/new/choose) and choose **Idea**: say what you
would like to do, and what problem it solves for you.

## Pull requests

Pull requests cannot be merged here. To suggest a change to the code or the text, open an issue and describe it
there. If it is taken in, it ships in a later version, and the [changelog](CHANGELOG.md) says so.

## A security problem

Do not open a public issue. Use **Report a vulnerability** on the repository's **Security and quality** tab.

## How we talk to each other

Everyone is welcome here, whether or not they have written code before. Please read the
[code of conduct](CODE_OF_CONDUCT.md).
